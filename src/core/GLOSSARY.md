# 共享核心

两个领域共用的知识图谱 RAG 流水线语言。这里只放**跨领域共享**的概念；领域特有的词不进这里。

## Language

### 知识表示

**知识图谱**：
以实体为节点、关系为边、并与原文证据双向可回溯的结构化知识表示。
_Avoid_: 语义网络、图数据库（那只是存储实现）

**本体**：
某个领域内允许出现的实体类型与关系类型的受控清单，是抽取的验收标准而非建议。
_Avoid_: 图 schema、数据模型

**三元组**：
一条「头实体—关系—尾实体」的断言，是本项目图谱写入的最小单位。
_Avoid_: 事实、知识条目

**证据段**：
文献中被抽取并保留原文位置的一条连续文字段落，是引用回溯的存储单位。
_Avoid_: 原文、片段、chunk

**引用锚点**：
证据段内的一个字符区间，指出支撑某条断言的那句原文。入库时定位并固化，查询期不再重新定位；片段必须在证据段里逐字存在，出现多次时取首次并标记歧义。没有锚点的证据段仍可按整段引用。
_Avoid_: 引用片段（那只是锚点截出来的文字）、高亮

### 流水线

**领域包**：
承载单个领域全部领域特有资产的目录（本体、抽取提示词、检索编排、金标准集）。
_Avoid_: 插件、子项目、模块

**抽取**：
从证据段中识别人工受控本体范围内的实体与关系，并写入图谱的过程。
_Avoid_: 信息提取、NER（后者只是抽取的子步骤）

**检索编排**：
决定一次提问该走哪些检索路径（向量召回、关键词召回、图遍历）及其先后与合并方式的领域逻辑。
_Avoid_: 检索策略、召回（后者只是编排中的一个环节）

**拒答**：
当证据不足以支撑结论时明确声明无法回答，而不是给出低置信度答案。
_Avoid_: 兜底、失败处理

### 评估

**金标准集**：
一组人工确认的「问题 + 期望答案要点 + 必须引用的出处」，用于衡量检索与回答的质量。
_Avoid_: 测试集、基准（避免与机器学习基准混淆）

**引用准确率**：
答案中的每个结论都能在其所标注的证据段原文中找到支撑的比例。
_Avoid_: 引用率、可溯源性
