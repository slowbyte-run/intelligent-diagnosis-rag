> **2026-11-13 更新：检索评估已改用冻结图谱快照（#32）。**
> 本文的 50 题数字是在会漂移的图上跑出的抽样，保留作历史对照与失败分析；
> 当前可重复基线、引用口径与运行命令见 [retrieval-eval.md](retrieval-eval.md)。
> 旧路径 `uv run --env-file .env idr eval --live-graph --corpus-dir data/input` 仍在，
> 但线上图已被重抽改写（本文记录 67 个概念 / 180 条边，现为 78 / 179），重跑得到的是
> 另一张图的分数，**不能用来复核本文数字**。两套评估的基线并排见
> [eval-baselines.md](eval-baselines.md)。
> 本文内部还有两代口径（概念+证据 → 证据），两代之间不可比，见「与 20 条基线对比」下的说明。

本票（#19）把金标准集从 20 条扩到 50 条，并按用户终审意见修订了 4 处；随后用一条命令跑出
M2 的三项指标与「因图失败」占比。语料与图谱沿用 M1/M2 的冻结快照（20 篇文献、67 个概念节点、

## ⚠ 后补：抽取不可复现，命中口径已改为证据口径

**这一节写于基线之后，它推翻了上面数字的解释方式，请先读这里。**

### 发现

追加锚点（#22）时全量重抽了一次语料，检索命中率从 95.8% 掉到 64.6%。当时归因于提示词加了「逐字引用」的要求，于是回滚提示词再抽一次——**仍然是 68.75%**，而那一版提示词正是产出 95.8% 的那一版。

直接测复现性：同一篇 `patent-CN104880291A`、同一提示词、温度 0，连续强制重抽两次：

| 运行 | 实体 | 关系 |
|---|---|---|
| 第一次 | 9 | 7 |
| 第二次 | 13 | 11 |

**抽取不是确定性的**，同一输入的产出相差约 50%。因此：

- 上面那些数字（61.1% / 77.8% / 95.8% / 64.6% / 68.75%）是**五次抽样**，不是能力的稳定估计；
- 之前把它们当作「策略改进的效果」来比较，结论不可靠——包括「对比意图把命中率从 77.1% 提到 95.8%」这种判断，其中一部分可能是抽样运气。

### 修正：命中口径改为证据口径

原来的命中要求「期望概念全部出现 **且** 至少命中一条期望证据 **且** 跨文献题覆盖全部文献」。其中**期望概念是某一次抽取的产物**，抽取一抖，分数就抖。

现在命中只要求 **证据命中 + （跨文献题）文献覆盖**。理由：证据段由固定的切分产生，重抽语料不会改变它们的 id；而概念集合会变。概念覆盖（`concept_ok` / `missing_concepts`）作为**独立诊断项**保留在报告里，不再参与命中判定。

### 新口径下的当前基线

| 指标 | 数值 |
|---|---|
| 检索命中率（证据口径） | 37/48 = **77.1%** |
| 事实型 | 20/24 = 83.3% |
| 对比型 | 9/12 = 75% |
| 跨文献型 | 8/12 = 66.7% |
| 引用准确率 | 845/845 = 100% |
| 拒答正确率 | 48/50 = 96% |

### 仍未解决的问题

改成证据口径只是**降低**了对抽取的敏感度，没有消除：图谱里没有指向该证据的事实边，题仍然过不了。要真正可比较，需要：

1. 固定抽取模型的版本，并实测其确定性；或
2. 对同一语料抽样多次、报告分布而不是单点；或
3. 把「检索」与「抽取」的评估彻底分开——用固定图谱测检索，用固定问题测抽取。

## 用户终审的 4 处修订

### 1. F-10「结构共振用什么方法确认？」撤下，由 F-11 替换

原题的期望概念里有模态测试，但期望证据（`66f9…:1:1327-1653`、`289961…:7:182-330`）讲的是
轴承座轴向共振与轴心轨迹，不是模态测试本身；问题与证据对不上，测不出任何东西。撤下后新增：

- **F-11 转子不平衡可以用哪些方法检测？**
  - 期望概念：`rotor_unbalance`、`fft_spectrum_analysis`、`field_balancing`
  - 期望证据：`ddaef…:6:570-1024`（专利：FFT + 包络取特征频率，按 1 倍频幅值占比报警）、
    `742178…:5:2290-2904`（热不平衡论文的 1X/2X/0.5X 级联谱）、`742178…:13:1241-1606`
    （现场动平衡把同步振幅压下去）

### 2. P-01「轴承外圈剥落和轴承内圈剥落怎么区分？」：保留问题，换证据

原期望是同一页两条 32 字公式碎片（`2270-2302` / `2313-2345`），单看碎片核对不出公式全貌。
改为同页的整段文字：

- `ev:4a8dc5af5de2cfe4:20:2091-2269`：「Fault frequency is given by」引入段（含滚动体/轴承
  频率的表格行）
- `ev:4a8dc5af5de2cfe4:20:2446-2660`：符号说明段（N、Fr、Rd、Pd、α）

**遗留问题**：OCR 把公式行本身切成了 9–52 字的碎片，而图上 `INDICATED_BY` 边只绑了那两条
碎片，所以这两段更好的期望在现有边证据下取不到。本题当前因「外圈/内圈命中同等具体」直接
拒答，报告里记为对比意图缺失。

### 3. X-02「轴承外圈剥落的检测手段在不同文献里有哪些？」：保留问题，换证据

原第三个文献（arxiv:2212 第 5 页）是用锤子敲外圈**制造**裂纹，原文还写「这个数据集无法只
检测内圈或外圈」；它是故障制造方式，不是检测手段。把它撤下，问题缩到两篇真正讲检测的文献：

- `ev:ddaef5ea68310f1b:6:5-291`：专利，FFT + 包络解调，按 BPFO/BPFI/BSF/FTF 判型
- `ev:906bd81774ba8b1a:33:5848-6279`：综述，频谱/PSD 识别故障振荡

两篇已满足跨文献定义，不再为凑三篇保留错误文献。

### 4. X-03「断齿的检测手段在不同文献中如何记载？」：保留问题，换证据

原期望一条是 989 字的结果段、一条是 3478 字的整页摘要，颗粒度太粗。换成两段更紧的段落：

- `ev:1be1ecd65c1482c8:6:493-1493`：4.2 特征提取段，19 个特征（12 时域 + 7 频域）
- `ev:4f88106f26629c63:4:1549-2086`：chipped tooth 实验段（50% 缺齿）

**映射 caveat**：图谱把「chipped tooth」映射到断齿，严格说 50% 缺齿不等于断齿，只能算近似。
**评测 caveat**：这两段都没有被 `DETECTED_BY` 边绑定（边只绑了 `4:68-81`、`5:294-1283`、
`8:2-1455` 与 4f881 整页 `1:445-3923`），所以当前检索引不到它们，本题在基线上失败。
这属于图谱边证据粒度问题，不是题目写错；要修得重建这几条边的 `evidence_ids`，超出本票范围。

## 没有出题的区域（图谱不支持，不硬编）

先查 Neo4j 再出题；以下区域**没有**进入 50 条，因为图上没有可绑定的规范节点或带证据的边：

1. **25 个本体实例没有图节点**：机械密封；轴承水分腐蚀、微动腐蚀、电蚀、过载塑性变形、
   颗粒压痕、热裂纹；齿面微点蚀、齿根疲劳裂纹、齿面塑性变形；定子相间短路、定子接地故障；
   静态/动态气隙偏心；以及 8 个原因（润滑剂污染、疲劳累积、腐蚀性环境、异物进入、过载运行、
   频繁启停、制造缺陷、基础刚度不足）；共振峰附近边带、电流频谱边带；绝缘测试。
   于是「润滑不良会引起什么」「气隙偏心怎么诊断」「绝缘测试怎么用」这类问题不能出。
2. **8 个有节点、但没有一条事实边的规范概念**：声发射检测、红外测温、汽轮机、润滑不良、轴电流、
   异常噪声、高频冲击信号、次同步振动。它们只能做拒答对照（R-01 就是汽轮机），不能做可答题。
3. **滚动轴承的「有哪些故障模式」问不出来**：以滚动轴承为起点时，一跳 `has_fault_mode`
   （13 条）会排在其故障模式的二跳征兆边之后，撞 20 条结果上界被截断，故障模式全被挤掉。
   这是遍历排序 + 上界的问题，不是图谱缺边；本次没有出这道题，但值得单独立票。
4. **电机侧证据质量差**：异步电机的「部件」边（轴承、鼠笼）证据多是参考文献条目或整页；
   转子断条、定子匝间短路的检测/征兆边也只有引用条目级证据，所以没出「异步电机包含哪些部件」
   「转子断条用什么检测」这类题。
5. **对称的 `confused_with` 只有 2 对能从较长别名一侧走到对侧**（不平衡↔结构共振、基础松动↔
   轴弯曲）；另外 5 对方向相反，按当前单起点遍历取不到对侧概念。这是对比型失败的主因之一。

## 「因图失败」占比（ADR-0006）

ADR-0006 的定义：问题「答案只能由图支撑、文字里只有『如图 X 所示』」。它要求 M2 统计这类
问题占比，**超过 15% 即重新立项**。

逐条检查 11 条失败：

- 9 条可以确定不是因图失败：P-01/P-02/P-03/P-07/P-08/P-09/P-12 的区分依据在文字里
  （公式、1X/2X 判据、鉴别表、特征频率），P-04 是别名缺口，X-03 是边证据粒度；
- P-10、P-11 是**疑似**因图失败：语料文字层里没有「磨粒磨损/粘着磨损」的区分（检索
  `磨粒磨损`、`粘着磨损` 两个词在 6806 个证据段里命中 0 次），c169 只用文字说「图 3/图 4
  是磨损/点蚀故障齿轮振动信号」，真正的波形在图里；86d0 的区分依据也可能是频谱图。没有
  视觉模型与 OCR，无法确认图里是否足以区分，故只记为疑似，不硬算。

因此：

- **确认因图失败：0/50 = 0%**；
- **疑似因图失败：2/50 = 4%**（P-10、P-11）；即使全部计入，也低于 15%。

但要明确这个数字的**选择偏差**：50 条题全部绑定了文字证据段，出题时就已经把「只能靠图回答」
的问题排除在外了；它度量的是「在这套可答题里，图缺失造成了多少失败」，不是「真实用户问题里
有多少只能靠图回答」。所以 0%（或上界 4%）**不能**用来判定 ADR-0006 的 15% 触发条件不成立。
要真正回答那个问题，需要一份不依赖图谱支持的用户问题样本，或对「含 Figure/图/如图」的 348
个证据段做抽样人工核对。另一个早期信号：本次通过但依赖图注的题已经出现（X-04 的期望证据
`289961…:7:182-330` 是一条 Figure 4 图注），说明图注文字有时能顶替图，但顶替不了图里的波形/
形貌信息。

1. **X-03 断齿检测**：chipped tooth 与断齿只是近似映射；期望的两段更紧证据当前取不到，
   本题在基线上必失败。要么重建边证据，要么把「chipped tooth」在题面里写清楚。

   在「问法比证据强」的范围里，且 P-11 的两个别名等长，实体链接直接判歧义。
3. **F-17 / F-18 齿面点蚀与断齿的征兆**：共用同一条 989 字段落，答案几乎一样，只能测概念

4. **F-21 / F-23 / F-25 单条证据题**：各只有 1 条引用（油液分析、FTF、频谱图），证据面太薄，
   引用准确率对它们几乎是送分。
5. **X-06 / X-07 共用同一对证据**（66f9 鉴别段 + 0015 表）；**X-02 / X-11 共用两段证据**，
   只是期望概念不同。它们能测「同一段证据能否挂到不同概念上」，但测不出「不同文献的描述
   差异」。
