# 云端模型为主，私有化降级路径必须常通

默认走云端 API（DeepSeek 负责生成与抽取，SiliconFlow 负责 embedding 与 rerank），所有模型调用收敛到 `src/core/llm` 适配层，业务代码不直接持有任何 provider SDK。私有化交付时只替换适配层实现为本地模型，调用方零改动。

选择云端优先，是因为本机 RTX 4060 只有 8 GB 显存，装不下 8B 级 embedding/rerank 模型（fp16 约 16 GB），而抽取是长上下文高频调用，本地小模型的质量与吞吐都不足以支撑验收级效果；同时私有化是这类项目最常见的成交条件，所以降级路径不能留到签约时才想。

## Consequences

- `EMBEDDING_DIM` 固定为 1024。8B/4B 模型需通过 MRL 截断到 1024，本地降级模型必须产出同维度向量，否则换模型即等于重建全部向量索引。
- 离线演示与内网客户共用同一条代码路径，不允许出现「演示用分支」。
