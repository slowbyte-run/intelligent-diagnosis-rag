# 抽取方差：为什么单次分数不能当能力估计

对应 issue #29。结论先给：**抽取端点不保证确定性，金标准单点分数是抽样结果，不是能力估计。**

## 一、查证结果

| 检查 | 做法 | 结果 |
|---|---|---|
| 服务端模型是否漂移 | 读响应里的 `model` 字段 | 稳定返回 `deepseek-v4.1-flash`，未观察到漂移 |
| `temperature=0` 是否足够 | 同一提示词连调 3 次 | **3 次 3 个不同输出** |
| `seed` 是否可补救 | 带 `seed=42` 连调 2 次 | 参数被接受，**两次仍不相同** |

所以：不是我们代码的问题，也不是温度的问题，是**服务端不承诺可复现**。

## 二、方差有多大

`idr variance <pdf> --runs 3` 对 `patent-CN104880291A.pdf` 的实测：

```
每次产出：
  #1  实体  12  关系  15  断言  27
  #2  实体  12  关系  10  断言  22
  #3  实体   4  关系   3  断言   7

实体数：[12, 12, 4]
关系数：[15, 10, 3]
断言集合两两重合（Jaccard 均值）：0.386
所有运行完全一致：否
```

**关系产出最多差 5 倍，断言集合平均只重合 38.6%。**

同一批语料的三次全量重抽，检索命中率分别是 95.8%、64.6%、68.75%——跨度 31 个百分点，用的都是同一份代码。

## 三、对既有结论的影响

- M1/M2 期间报告的版本间对比（61.1% → 77.8% → 95.8%）**都可能混入抽样噪声**；
- 「对比意图把命中率提到 95.8%」这类判断，其中一部分可能是运气；
- 任何「今天比昨天好」的结论，在单次抽样上都站不住。

已做的缓解：命中口径改为**证据口径**（证据段由固定切分产生，不随抽取变），期望概念降级为独立诊断项。这降低了敏感度，**没有消除**方差。

## 四、怎么用这个工具

```bash
export UV_CACHE_DIR=$PWD/.uv-cache
uv run --env-file .env idr variance data/input/arxiv-2403_17181.pdf --runs 3 --out data/output/reports/variance.json
```

输出每次运行的实体数、关系数、断言数，以及两两 Jaccard 重合度与「是否完全一致」。

**在评估任何抽取侧改动（提示词、本体、分批参数）之前，先跑这个。** 如果改动的效果小于方差，那这个改动就是测不出来的。

## 五、还没解决

1. 方差本身没有被降低。可能的着力点：更结构化的输出约束、更小的分批让模型更聚焦、或在提示词里给出示例。
2. 金标准报告仍是单点。要变成区间，需要同一语料抽样 N 次（N≥3）并重跑评估，成本是 N 倍重抽。
3. 「检索」与「抽取」的评估还没拆开：固定图谱测检索、固定问题测抽取，两件事的稳定性要求不同。

## 六、后续（2026-11-13）

「重复运行 + 分布」的表达已经落到两处：`idr variance` 继续测单篇抽取的方差，`idr extract-eval` 则对标注集重复 N 次并报告召回/精度的分布与两两重合度（默认 3 次，见 `docs/extraction-evaluation.md` 第六节）。检索侧改用固定图谱快照，不再受重抽影响。本页记录的问题是这两处共同的前提，结论不变：**单次分数不是能力估计**。
